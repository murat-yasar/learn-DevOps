# Docker File
> A Dockerfile is a text file containing instructions that Docker uses to build a Docker image.

Think of it this way:
- Dockerfile: The recipe.
- Docker image: The finished package.
- Docker container: A running instance of that package.

## 1. Example: a simple Dockerfile for a PHP application
```dockerfile
# 1. Choose the base image
FROM php:8.3-apache

# 2. Set the working directory
WORKDIR /var/www/html

# 3. Install system dependencies
RUN apt-get update && apt-get install -y \
    git \
    unzip \
    libzip-dev

# 4. Install PHP extensions
RUN docker-php-ext-install zip mysqli pdo_mysql

# 5. Copy application files
COPY . /var/www/html

# 6. Set permissions
RUN chown -R www-data:www-data /var/www/html

# 7. Expose Apache port
EXPOSE 80

# 8. Start Apache
CMD ["apache2-foreground"]
```

## 2. Dockerfile instructions
| Instruction	| Purpose |
| ----------- | ------- |
| FROM |	Defines the base image |
| WORKDIR |	Sets the working directory inside the container |
| RUN |	Executes commands during image building |
| COPY |	Copies files from your computer into the image |
| ADD	| Copies files (with additional capabilities) |
| EXPOSE |	Documents which port the container uses |
| ENV |	Defines environment variables |
| ARG |	Defines build-time variables |
| CMD |	Defines the default command when the container starts |
| ENTRYPOINT |	Defines the main executable of the container |
| USER |	Sets the user that executes subsequent instructions |
| VOLUME |	Defines a mount point for persistent data |

## 3. How to build and run an image
The project structure:
```
my-php-project/
├── Dockerfile
├── index.php
└── composer.json
```

```sh
# 0. Go to the project-root
cd cd my-php-project

# 1. Build the image
docker build -t my-php-app .
# docker build     : Build the image
# -t my-php-app    : Tag the image as my-php-app
# .                : Build the current directory as the build context

# 2. Run a container
docker run -d -p 8080:80 --name my-php-container my-php-app
# -d          : Run in the background
# -p 8080:80  : Map host port 8080 to container port 80
# --name      : Give the container a name
# my-php-app  : Use the image

# 3. Inspect containers
docker ps

# 4. Open application on browser
# http://localhost:8080

# 5. View logs
docker logs my-php-container

# 6. Stop container
docker stop my-php-container
```

> Open your application: http://localhost:8080
